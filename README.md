# NYC Año Nuevo 2027 · Itinerario

Sitio estático para planear un viaje de 4 amigos a New York del 27 de diciembre de 2026 al 2 de enero de 2027.

## Recomendación resumida

- Dormir en NoMad / Bryant Park / Central Park South, no necesariamente en Times Square.
- Comprar evento NYE con vista garantizada a la bola.
- Presupuesto realista sin vuelos: **US$18k–30k** para 4 si quieren cosas buenas.

## Deploy en Vercel

Importar este repo en Vercel como proyecto estático. No requiere build command.

Repo: https://github.com/eduardoivan86/nyc-nye-2027-itinerary
